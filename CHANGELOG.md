# Changelog

## 0.0.2 - 2026-10-10

- Added live editing for selected-track MIDI channel, probability, velocity, and gate length.
- Added editing for Euclidean rhythm settings, random-walk pitch/root/scale, and sequence length, notes, and rests.
- Added a settings panel and current step/mute state to the terminal UI.
- Made the global seed generate deterministic musical settings for all tracks while keeping their MIDI channel assignments stable.

## 0.0.1 - 2026-10-09

- Added MIDI output selection, internal clock, transport, and three algorithmic demo tracks.
- Added seeded random walk, Euclidean rhythm, scale quantization, probability, and MIDI note cleanup.
